# C-Movin

Organizador de arquivos para Mac, com IA que roda direto no seu computador.

Este repositório hospeda a página de suporte e a política de privacidade do app, publicadas via GitHub Pages.

## Conteúdo

- `index.html`: página de suporte, perguntas frequentes e política de privacidade (`#privacidade`)

## Sobre o app

- Classifica imagens e PDFs com IA local (nada sai do Mac)
- Mostra pra onde cada arquivo foi e permite desfazer a rodada
- Modo vigia: avisa por notificação e só move com a sua aprovação
- Requer macOS 26 ou superior e Mac com Apple Silicon
